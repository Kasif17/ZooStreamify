# 🦓 ZooStreamify  

ZooStreamify is a **full-stack MERN web application** that allows users to **connect, chat, video call, share screens, and record lectures** – all in one place.  
It uses **JWT authentication**, real-time chat powered by **Stream Chat API**, and a beautiful responsive UI.

---

## 🚀 Features  

✅ **User Authentication** – Secure login/signup with JWT and protected routes  
✅ **Real-time Chat** – One-to-one chat with message history  
✅ **Video Calling** – Start a video call directly from chat  
✅ **Screen Sharing** – Share your screen during calls  
✅ **Lecture Recording** – Record and save calls for later review  
✅ **Friend System** – Send/accept friend requests & see online users  
✅ **Notifications** – Get instant updates for friend requests  
✅ **Responsive UI** – Works perfectly on mobile and desktop  

---

## 🛠️ Tech Stack  

- **Frontend:** React, Tailwind CSS, React Router, React Query  
- **Backend:** Node.js, Express.js, MongoDB  
- **Real-time Communication:** Stream Chat API  
- **Authentication:** JWT (JSON Web Tokens)  
- **Hosting:** Render (Backend), Netlify/Vercel (Frontend)
